# Content Hub

This repository contains two independent applications:

- [`backend/`](backend/README.md) — NestJS GraphQL API, Prisma, PostgreSQL, and Redis.
- [`frontend/`](frontend/README.md) — React and TypeScript application created with Vite.

Install dependencies and run commands from the application directory you are working in. The API uses port 3000 by default; the Vite development server uses port 5173. The frontend is currently a starter project and does not call the API yet.

Planning documents and tasks remain at the repository root in `docs/`, `.scratch/`, `.ua/`, `AGENTS.md`, and `GLOSSARY.md`. These local files are excluded from Git by `.gitignore`.
